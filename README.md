## How to Use These Handbooks

1. **Quick Revision** — Read the "Quick Reference" tables for a fast refresher
2. **Deep Dive** — Study the "Medium Depth" sections for commonly asked or confusing topics
3. **Interview Prep** — Focus on the "Interview Focus" boxes at the end of each chapter — these are the exact questions interviewers ask

## Format

Each handbook follows a consistent structure:
- **Medium Depth** — Concepts with explanation + concrete examples
- **Quick Reference** — Compact tables for fast scanning and memorization
- **Interview Focus** — Exact questions to expect in interviews
